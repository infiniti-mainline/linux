# Contributing

- Every commit needs a `Signed-off-by:` (DCO 1.1) under a known identity,
  same as mainline. No CLA, ever.
- One logical change per commit, kernel style, checkpatch-clean where
  practical. Preserve third-party authorship — never squash someone
  else's commit into yours.
- Work on branches named `review/<your-handle>/<topic>` and open a PR
  against `oneplus-15`. `oneplus-15` and `development` are never
  force-pushed.
- If an AI coding tool materially contributed to a change, say so in the
  PR; upstream submissions additionally follow the kernel's current
  generated-content and Assisted-by disclosure rules.
- Upstream submissions are re-curated as proper mailing-list series from
  reviewed work here; landing in this repo is not itself an upstream
  submission.
